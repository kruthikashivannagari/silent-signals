# Silent Signals – AI Safety Companion for Women

Silent Signals is a prototype safety platform designed to help women discreetly document abuse incidents and detect distress signals.

## Problem
Many women in abusive or unsafe environments cannot openly ask for help because communication may be monitored or restricted.

## Solution
Silent Signals provides a discreet platform that allows users to privately log incidents, analyze distress signals, and alert trusted contacts.

## Key Features
• Hidden safety dashboard  
• Incident logging  
• Distress detection using text analysis  
• Emergency alert button  
• Trusted contacts list  
• Incident history  
• Safety resources and helplines  

## Technology Stack
• React.js  
• JavaScript  
• Node.js  
• CSS  

## How the Prototype Works
1. User unlocks the hidden safety dashboard.
2. User logs an incident describing the situation.
3. The system analyzes the text to detect distress signals.
4. If risk is detected, the system alerts trusted contacts.
5. The incident is stored in the history for documentation.
